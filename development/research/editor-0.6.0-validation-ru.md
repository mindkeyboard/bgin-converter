# Проверка локальной версии 0.6.0

Дата: 2026-11-14. Пакет: `dist/bgin-editor-0.6.0-win32-x64.vsix`.
Публикация и установка в рабочий профиль пользователя не выполнялись.

Результат и ограничения описаны в [руководстве](../editor-0.6-ru.md).
Контрольные суммы пакета, исходников, встроенного модуля, отчёта компилятора
и журналов сохранены в [метаданных проверки](editor-0.6.0-validation.json).
Изменения остаются в рабочем дереве отдельного репозитория редактора.

Исправлена потеря истории отмены после сохранения: `workspace.fs.rename`
рассматривался VS Code как перемещение файла и очищал историю назначения.
Теперь локальный файл заменяется через файловую систему после независимой
проверки и создания резервной копии. Отмена после сохранения проверяется
настоящим Extension Host. Безопасное сохранение требует локального файла.

Граф компонента обновлён по изменённым файлам без новых субагентов:
1567 узлов, 3623 связи. 37 модулей сопоставлены с сгенерированным C-кодом
компилятора; среди них нет исходников новее сгенерированного кода.
Это дополнительная проверка соответствия, а не доказательство воспроизводимой сборки.

## Не проверено или не поддержано

- Загрузка изменённых BGIN и перекодированных текстур игрой не проверялась.
- Специальные записи второй таблицы и два несогласованных каталога 3.7.0
  отклоняются. Сохранение неподдерживаемого файла не заявлено.
- Предпросмотр сохраняет новые варианты свойств и цветовые каналы, но пока
  не воспроизводит их выбор и поведение нового движка.
- Встроенный модуль обслуживает RPC редактора. Для адаптера MCP через stdio
  нужен отдельный Python с дополнением `mcp` этого проекта.
- Получение уведомления MCP не гарантирует немедленное обновление контекста
  уже работающей модели: это зависит от клиента. Устаревшие правки отклоняются.

Журналы находятся во внешнем рабочем каталоге, задаваемом как
`BGIN_RESEARCH_ROOT`; их имена и SHA-256 перечислены в метаданных проверки.
Оригинальные ресурсы, архивы, ELF и данные телефона не изменялись.
