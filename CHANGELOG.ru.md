# Изменения

## 0.5.0 — 2026-11-07

- Отдельные пакеты предусмотрены для Windows x64 и ARM64, macOS Intel и Apple
  Silicon, Linux x64, ARM64 и ARMv7, а также Alpine x64 и ARM64.
- В каждом VSIX есть скомпилированный модуль BGIN и библиотеки предпросмотра.
  Устанавливать системный Python и загружать зависимости при первом запуске не нужно.

## 0.4.16 — 2026-11-02

- Исправлена вставка объекта в контейнер, если скопированный JSON содержит
  запятую из списка, обрамление блока JSON или поля без внешних фигурных скобок.
- Некорректное содержимое буфера теперь сопровождается понятным сообщением
  и не изменяет документ.
- При вставке сохраняются свойства вложенных объектов и ссылки на ресурсы.
