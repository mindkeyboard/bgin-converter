# Изменения

## 0.6.3 — 2026-11-14

- Адаптер MCP, зависимости и браузерный драйвер включены в исполняемый модуль. В левой панели копируются готовая команда или JSON подключения; Python и pip не нужны.
- В проверку пакета добавлены подключение MCP, инструкция, чтение, правка и независимый экспорт без Python в PATH.
- Если отдельного Chromium нет, рендер MCP использует установленный Chrome или Edge.

## 0.6.2 — 2026-11-14

- В окне выбора рядом с каждым экраном показано число объектов: сам корень
  и все вложенные объекты, включая дорожки. Работает в обоих представлениях;
  количество вычисляется один раз при открытии окна.

## 0.6.1 — 2026-11-14

- Просмотр уже открытого экрана: разнесение веток с выбором глубины, рентген
  и отсечение верхних слоёв. Используется готовый рендер с сохранением расчёта
  геометрии родителей; BGIN не меняется, новый рендер не запускается.
- Вместо списка экранов — окно с поиском, общим списком и группировкой
  по вычисленным префиксам. Список виртуализирован.

## 0.6.0 — 2026-11-14

- Четыре явных режима BGIN (~0.0.2, ~1.6.0, ~3.7.0, ~5.8.0) сохраняются при
  записи. Отдельная конвертация отклоняет потерю данных. Неподдержанные специальные
  записи и несогласованные каталоги дают явную ошибку.
- Несколько MCP-клиентов работают с общим несохранённым документом, ревизиями
  и отменой VS Code. В панели видны действия; клиента можно приостановить,
  остановить или отключить. Рендеры видны в редакторе, устаревшие отмечены.
- Автозаполнение ресурсов поддерживает неполную распакованную zdata/PAD наряду
  с прежними архивами. Нужные текстуры читаются из JPK без полной распаковки игры.
- Предпросмотр декодирует ETC2/ASTC и оболочки LZ4/старого Zstd. Отдельная
  команда экспортирует PVR без оболочки либо RGBA8; загрузка игрой ещё не проверена.
  Сохранение BGIN не запускает конвертацию текстур.

## 0.5.0 — 2026-11-07

- Отдельные пакеты предусмотрены для Windows x64 и ARM64, macOS Intel и Apple
  Silicon, Linux x64, ARM64 и ARMv7, а также Alpine x64 и ARM64.
- В каждом VSIX есть скомпилированный модуль BGIN и библиотеки предпросмотра.
  Устанавливать системный Python и загружать зависимости при первом запуске не нужно.

## 0.4.16 — 2026-11-02

- Исправлена вставка объекта в контейнер, если скопированный JSON содержит
  запятую из списка, обрамление блока JSON или поля без внешних фигурных скобок.
- Некорректное содержимое буфера теперь сопровождается понятным сообщением
  и не изменяет документ.
- При вставке сохраняются свойства вложенных объектов и ссылки на ресурсы.
