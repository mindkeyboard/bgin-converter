# Binary GIN Editor

Открывайте, редактируйте и просматривайте игровые интерфейсы `.bgin` в VS Code.

## Быстрая установка

В VS Code 1.105 или новее откройте **Extensions → … → Install from VSIX…**
и выберите пакет для своей платформы. Модуль BGIN входит в пакет, поэтому
устанавливать Python отдельно не нужно.

Версия 0.6.3: [режимы, ресурсы zdata и подключение MCP](development/editor-0.6-ru.md).

Числа режимов ~0.0.2, ~1.6.0, ~3.7.0 и ~5.8.0 обозначают форматы BGIN на момент выхода соответствующих версий Asphalt 8, а не строгую привязку к версии игры. Можно пробовать файлы соседних выпусков A8 и других игр того же периода; совместимость определяется структурой файла и не гарантируется. Сохранение удерживает исходный формат, а преобразование в другой режим выбирается явно. Текстуры конвертируются отдельно.
