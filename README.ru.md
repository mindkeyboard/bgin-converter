# Binary GIN Editor

Редактор игровых интерфейсов `.bgin` для VS Code: дерево объектов, изменение
свойств и предпросмотр. BGIN открывается напрямую. Получение отдельного JSON —
дополнительная возможность.

Автор: **mindkeyboard**. Использование регулируется приложенными условиями.

[Полное руководство](https://octane-loader.utmsoft.ru/ru/guide/octane-devtools/bgin-editor/v0.5.0/)
· [English](README.md)

## Выбор пакета

| Среда | Суффикс файла |
| --- | --- |
| Windows x64 / ARM64 | `win32-x64` / `win32-arm64` |
| macOS Intel / Apple Silicon | `darwin-x64` / `darwin-arm64` |
| Linux с glibc, x64 / ARM64 / ARMv7 с аппаратной плавающей точкой | `linux-x64` / `linux-arm64` / `linux-armhf` |
| Alpine Linux с musl, x64 / ARM64 | `alpine-x64` / `alpine-arm64` |

При работе через WSL, SSH или Dev Containers ориентируйтесь на ОС и архитектуру
удалённой среды, где открыта рабочая область. Сборки Linux рассчитаны на glibc
2.36 и новее, сборки Alpine — на Alpine 3.23 и новее. Для редактора нужен
VS Code с нативной средой выполнения расширений.

## Первый запуск

1. Если вы получили ZIP, распакуйте его в обычную папку.
2. Установите [VS Code](https://code.visualstudio.com/download) 1.105 или новее.
   Откройте **Extensions**, затем **… → Install from VSIX…** и выберите
   приложенный `bgin-editor-….vsix`. Согласитесь на перезагрузку окна, если она предложена.
3. Если в архиве есть `Preview.code-workspace`, откройте его через **File → Open
   Workspace from File…**, чтобы подключить ресурсы предпросмотра. Оставьте этот
   файл рядом с папкой `resources`. Если вы доверяете комплекту, подтвердите
   доверие к папке при запросе VS Code.
4. Откройте `.bgin`. Если вместо редактора появился текст, нажмите правой
   кнопкой по вкладке → **Reopen Editor With… → Binary GIN**.
   При первом открытии прочитайте и примите условия.
5. Выберите **Screen** и нажмите **Refresh** для предпросмотра. Выделите объект
   и измените свойства. **Refresh** покажет изменения, **Ctrl+S** (на macOS **⌘S**) сохранит файл.

Модуль BGIN и библиотеки предпросмотра входят в VSIX. Устанавливать Python,
менять `PATH` и загружать компоненты при первом запуске не нужно.

## Если не открывается

- Открылось как текст: правая кнопка по вкладке → **Reopen Editor With… → Binary GIN**.
- Ошибка осталась: откройте **View → Output**, в списке журналов выберите
  **Binary GIN** вместо **Window** и скопируйте текст ошибки.
- Дерево есть, а картинки нет: откройте `Preview.code-workspace` или укажите
  свои папки через **Resources**, затем нажмите **Refresh**.

[Подробное решение проблем](https://octane-loader.utmsoft.ru/ru/guide/octane-devtools/bgin-editor/v0.5.0/troubleshooting).
Русский язык кнопок включается в **Editor settings → Interface language → Русский**.

Сохраняйте копии исходных файлов перед заменой их в игре. Предпросмотр может
отличаться от игры и не запускает игровые действия. Закрытие первого окна
условий не означает согласия. После первого закрытия или принятия условий
однократно открывается [Telegram-канал Octane](https://t.me/octaneloader).
