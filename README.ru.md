# Binary GIN Editor

Открывайте, редактируйте и просматривайте игровые интерфейсы `.bgin` в VS Code.

## Быстрая установка

В VS Code 1.105 или новее откройте **Extensions → … → Install from VSIX…**
и выберите пакет для своей платформы. Модуль BGIN входит в пакет, поэтому
устанавливать Python отдельно не нужно.
