# Композиция интерфейса

Создавай понятный привычный интерфейс: название экрана, основная задача, относящиеся к ней сведения и действия. Воспроизводи визуальный образец пользователя и уже существующие элементы продукта. Без образца выбери спокойную согласованную композицию с различимыми заголовками, одинаковыми отступами и предсказуемым размещением кнопок. Не навязывай всем экранам одну палитру или обязательную декоративную рамку.

Дерево должно объяснять смысл групп. Обычно внешний `MarginContainer` задаёт поля, `VerticalContainer` разделяет верхнюю панель, основную область и действия. В верхней панели `HorizontalContainer` объединяет заголовок и навигацию; основная область содержит самостоятельные карточки/секции; нижняя группа объединяет связанные кнопки. `StackContainer` полезен внутри карточки для наложения фона и содержимого. Он не заменяет размещение всех соседей экрана. Один большой контейнер с десятками вручную сдвинутых детей усложняет адаптацию и редактирование.

Настоящие рисунки и текстовые стили бери из проверенных подключённых библиотек. Перед изменением существующего экрана изучи его соседние экраны, `Widgets` и `Sprites`: названия кнопок не доказывают наличие подходящего оформления. Для картинок сохраняй пропорции через Movie Fit/Fill и соответствующую область; для полос и панелей используй подтверждённые растягиваемые ресурсы. Не заменяй отсутствующие ресурсы случайными встроенными изображениями.

Ниже небольшой кодируемый документ с семантическими группами. Это основа компоновки с текстом и кнопками; для оформления добавь реальные ссылки `TextStyle` и фоновые ресурсы из своего проекта. Внешние текстуры не требуются, но без заданного шрифта просмотр может использовать запасной шрифт. Действия кнопок подключаются кодом игры отдельно.

```json
{
  "name":"GarageMenu",
  "dialect":"ui",
  "screens":[{
    "type":"MarginContainer","name":"main",
    "properties":{"MarginFactors":[4,4,4,4]},
    "children":[{
      "type":"VerticalContainer","name":"screen_sections",
      "properties":{"Spacing":4,"SpacingPolicy":{"enum":"Mm"}},
      "children":[
        {"type":"HorizontalContainer","name":"header","properties":{"MinSize":[0,56],"Spacing":3},"children":[
          {"type":"Label","name":"title","properties":{"TestString":"Гараж","StretchFactor":1}},
          {"type":"Button","name":"back","properties":{"TestString":"Назад","MinSize":[120,48]}}
        ]},
        {"type":"MarginContainer","name":"vehicle_details","properties":{"StretchFactor":1,"MarginFactors":[3,3,3,3]},"children":[
          {"type":"VerticalContainer","name":"vehicle_summary","properties":{"Spacing":3},"children":[
            {"type":"Label","name":"vehicle_name","properties":{"TestString":"Мой автомобиль","MinSize":[0,40]}},
            {"type":"TextArea","name":"description","properties":{"TestString":"Выберите улучшение или продолжите заезд.","FontHeightFactor":3,"StretchFactor":1}}
          ]}
        ]},
        {"type":"HorizontalContainer","name":"actions","properties":{"MinSize":[0,56],"Spacing":4},"children":[
          {"type":"HorizontalSpring","name":"actions_space","properties":{"StretchFactor":1}},
          {"type":"Button","name":"upgrade","properties":{"TestString":"Улучшить","MinSize":[160,48]}},
          {"type":"Button","name":"race","properties":{"TestString":"Заезд","MinSize":[160,48]}}
        ]}
      ]
    }]
  }]
}
```

Для оценки композиции сначала смотри полный экран, затем конкретную ветвь через `options.selected` на исходном документе. Вырезанный ребёнок потеряет размеры родителей и участие соседей. Для проверки численных границ добавь `include_geometry: true` в запрос рендера. Размер изображения `options.width`/`height` определяет расчёт компоновки; `tile_width`/`tile_height` лишь масштабирует полученную картинку на листе сравнения.

Проверь целевое разрешение и хотя бы один существенно иной формат, если интерфейс должен адаптироваться. Для кнопок сравни normal/pressed/disabled, для переключаемых — toggled. Проверяй длинные подписи, переносы, нижние действия, столкновения и отступы; для локализации — нужный `language`, ресурс шрифта и фактические строки. Вызов с 1–36 запросами вернёт не более девяти изображений на листе и JSON-индекс с предупреждениями. Сравнивай варианты с одинаковыми ресурсами и масштабом.

При сдаче покажи итоговый вид и сохранённый JSON, перечисли недоступные ресурсы и ограничения просмотра. Не называй статический дизайн проверенным игровым экраном, пока нет испытания в игре.
